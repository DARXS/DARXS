## 👋 Hi, I'm Danilo

I investigate automotive software failures, trace them to root cause, and help make sure reliable fixes reach production. I started as an embedded developer building ECUs and firmware from scratch, and today I work on the quality and diagnostics side of the same world.

- 🔭 **Now:** In-Field Software Quality Analyst at **Stellantis South America** (via ACT Digital), reproducing field failures on multicore ECUs (Infotainment, IPC, TBM) on bench, HIL and vehicle.
- 🚗 **Day to day:** UDS (ISO 14229) over CAN and DoIP, CAN/LIN network analysis, ECU flashing, FOTA/AOTA/MOTA validation, and warranty KPIs (3MIS/12MIS, PPM, FTY).
- 🛠️ **Before:** designed ECUs, PCBs (KiCad) and C/C++ firmware for the **Mangue Baja SAE** off-road prototype at UFPE, growing from developer to team lead.
- 📊 **Also:** Power BI dashboards (DAX, Power Query) for field-quality tracking.
- 🎓 **Studying:** Mechatronics, Robotics and Automation Engineering at IFMG.
- 🎯 **Interested in:** automotive software quality, ECU diagnostics, systems engineering, embedded systems and Software-Defined Vehicles.

### 📡 Vehicle Processing & Telemetry Module

`C++` `ESP32` `KiCad` `CAN` `LoRa`

Custom hardware (KiCad) and ESP32 firmware that listens to a multi-node CAN network (IMU, RPM, speed, temperature, SOC), parses GPS over UART (TinyGPSPlus) and transmits over LoRa, using a ticker-driven circular buffer.

**Result:** real-time telemetry with **1.5 km LoRa range**.

### ⏱️ Distributed Acceleration & Speed Timer

`C++` `ESP32` `ESP-NOW` `FSM` `I2C`

Distributed ESP32 system for 30 m / 100 m acceleration and speed tests: peer-to-peer state machine over ESP-NOW, a signal-repeating bridge module, infrared sensors, I2C LCD driver, CSV logging to SD, and timestamp sync across 3 independent nodes.

**Result:** a modular timing system that runs on the track without cables between nodes.
